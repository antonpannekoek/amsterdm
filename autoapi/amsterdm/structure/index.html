amsterdm.structure¶

Module to compute a best estimate for the dispersion measure, including an error estimate.

Following the publication of Sutinjo et al, 2023, 10.3847/1538-4357/ace774 . Please cite this publication if you are using this code.

Code adopted from initial code provided by T Perrott, with additions from A Bera and M Glowacki and based on earlier code by by A Sutinjo and a script by D Scott. See https://github.com/marcinglowacki/SHRINE

class amsterdm.structure.Structure(data: amsterdm.constants.Array, dms: numpy.ndarray, kc: int | None = None)¶

Class to hold the structure data and calculation results

While the actual calculation can be a straightforward function, additional functionality such as creating diagnostic plots require the intermediate calculated data. These are kept as part of the class, and then plots can be optionally created after the initial calculation.

If you use this functionality of AmsterDM, please cite Sutinjo et al, 2023, 10.3847/1538-4357/ace774

Obtain best estimate for the spectral cutoff parameter k_c

Parameters:
